## Тестирование

Проект полностью покрыт тестами (более 80% покрытия кода). 

### Запуск тестов
Для запуска всех тестов выполните команду в терминале:
```bash
poetry run pytest
```

### Отчет о покрытии (Coverage)
Для генерации и просмотра HTML-отчета о покрытии тестами выполните:
```bash
poetry run pytest --cov=src --cov-report=html
```
После этого откройте файл `htmlcov/index.html` в вашем браузере, чтобы увидеть подробный отчет.
